name: Rent Clock campaign claims
description: Boundaries for tribunal comparisons, payout claims and application handoff.
---

The user requires the Rent Clock to be an educational campaign, not a live
tribunal tracker. Ontario's 240 days is an illustration (8 × 30); BC and Alberta
have no connected figures. Quebec/TAL must not be added to the tracker.
The one-day payout is a proposed campaign claim, not a confirmed benefit.

**Why:** The supplied campaign brief explicitly prohibits invented wait times,
coverage terms, endorsements and confirmed payment promises. These constraints
must survive later promotional rewrites.

**How to apply:** Keep the disclosures visible in both the landing page and
embedded clock. Only replace illustrations with verified sourced data and
approved benefit terms. Calculator use must not submit an application or activate
coverage; its calls to action lead to the existing Rent Guarantee application.
