---
name: Organic guide launch
description: Editorial and measurement rules from the QuoteUs.ca organic search brief.
---

Keep editorial drafts unpublished until approved by an actual author or reviewer.
Show a real name and last reviewed date. Use authoritative Ontario sources for
rules and approved provider documents for product terms. Do not mass-produce
near-identical city pages.

**Why:** The user prioritizes useful resources that generate completed quote
requests, not search visibility for low-value pages.

**How to apply:** Put approved content and quote links in public initial HTML.
Measure organic quote completions alongside Google Search Console impressions
and clicks, using comparable 30-, 60-, and 90-day checkpoints. Never infer
Google index coverage from HTTP status or sitemap membership.
